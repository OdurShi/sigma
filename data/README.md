# Data

This folder contains the three intent-classification benchmarks used by the experiments of
the paper, converted to JSONL, together with the artefacts derived from them (hierarchies,
task records, rendered guidance documents, nested few-shot orderings), and the synthetic
task of the quick start. The code reads these files by default, so a clone runs without
further downloads.

| Dataset | Used by | Intents | Training pool | Development | Test | Licence |
|---|---|---|---|---|---|---|
| BANKING77 | all main experiments (Tables 1, 2, 4, 5, 7, 10–14; Figures 4–8) | 77 | 8,622 | 1,540 | 3,080 | CC BY 4.0 |
| CLINC150 (in-scope intents) | all main experiments; `configs/experiments/figure2_preliminary.yaml` | 150 | 15,000 | 3,000 | 4,500 | CC BY 3.0 |
| HWU64 | all main experiments | 64 | 8,954 | 1,076 | 1,076 | CC BY 4.0 |
| Synthetic routing task | quick start (`sigma demo`), tests | 6 | 96 | 24 | 48 | generated by this repository (MIT) |

The split sizes are those of Table 3 of the paper.

## Where the code looks for data

`sigma.data.datasets.resolve_data_dir` uses, in this order, the environment variable
`SIGMA_DATA_DIR`, the configured directory (`data.directory` in a config file, or
`--data-dir` on `sigma train` / `sigma experiment`) if it exists, and this `data/` folder of
the checkout. A benchmark is downloaded only when its folder is missing.

## File layout

```text
data/
  <dataset>/                 banking77, clinc150, hwu64
    train.jsonl              training pool, one {"text": ..., "label": ...} per line
    valid.jsonl              development split
    test.jsonl               test split
    hierarchy.json           sibling groups of the intents and how they were obtained
    task.json                task record: tree, node descriptions, base output binding
    guidance.txt             the rendered base guidance document g0
    fewshot/seed<seed>.json  nested few-shot orderings for seeds 13, 21, 42, 87, 100
    manifest.json            upstream source, revision and SHA-256 of the upstream files
  synthetic/quickstart/      train.jsonl, valid.jsonl, test.jsonl, task.json, guidance.txt,
                             manifest.json
  SHA256SUMS                 checksums of all files above
  raw/                       download cache of the upstream files (not tracked)
```

`python scripts/prepare_data.py --dataset all` rebuilds every file from the upstream
sources (pinned to the revisions below) and refreshes `SHA256SUMS`. An existing
`hierarchy.json` is reused; recomputing the BANKING77 label clusters needs the `data` extra
(`pip install -e ".[data]"`).

## Sources, versions and licences

All three benchmarks are taken from the public few-shot intent-detection release
<https://github.com/jianguoz/Few-Shot-Intent-Detection> (revision
`fa9553312b1dba54b1be0aae2d30b13171f898e5`, folders `Datasets/BANKING77`,
`Datasets/CLINC150`, `Datasets/HWU64`), which provides the train / validation / test splits
used in the paper as aligned `seq.in` and `label` text files. That repository does not carry
a licence file of its own; the files are redistributed here under the licences of the
original datasets, with attribution, as listed below. Changes made here: each split was
converted to JSONL (surrounding whitespace stripped); utterances and labels are unchanged.

**BANKING77.** Online-banking customer queries labeled with 77 intents. Original dataset:
<https://github.com/PolyAI-LDN/task-specific-datasets> (PolyAI), introduced in "Efficient
Intent Detection with Dual Sentence Encoders" (Casanueva et al., 2020). Licence: Creative
Commons Attribution 4.0 International, <https://creativecommons.org/licenses/by/4.0/>.

**CLINC150.** Queries from ten domains labeled with 150 in-scope intents (out-of-scope
queries are not included). Original dataset: <https://github.com/clinc/oos-eval>, introduced
in "An Evaluation Dataset for Intent Classification and Out-of-Scope Prediction" (Larson et
al., 2019). Licence: Creative Commons Attribution 3.0 Unported,
<https://creativecommons.org/licenses/by/3.0/>. The domain-to-intent mapping in
`clinc150/hierarchy.json` is the file `domains.json` of that repository (its `data` folder) at
revision `828f8093932c8fe6ca7936c3d2e52903b1c523de`.

**HWU64.** Personal-assistant queries labeled with 64 intents from 18 scenarios. Original
dataset: <https://github.com/xliuhw/NLU-Evaluation-Data>, introduced in "Benchmarking Natural
Language Understanding Services for building Conversational Agents" (Liu et al., 2019).
Licence: Creative Commons Attribution 4.0 International,
<https://creativecommons.org/licenses/by/4.0/>.

## Derived artefacts

**Hierarchies and guidance documents** (Appendix C.2 of the paper). Every task is a
root → group → intent tree; the outputs are the original intent strings with identity
bindings, and `guidance.txt` is the base guidance document rendered from `task.json`.

| Dataset | Groups | How the groups are obtained |
|---|---|---|
| BANKING77 | 9 label clusters (sizes 42, 18, 5, 4, 3, 2, 1, 1, 1) | `sentence-transformers/all-mpnet-base-v2` embeddings of the label names, cosine distance, average linkage, cut into ⌈√77⌉ = 9 groups |
| CLINC150 | 10 domains of 15 intents | published domain metadata |
| HWU64 | 18 scenarios (sizes 10, 9, 5, 5, 4, 4, 3, 3, 3, 3, 3, 3, 2, 2, 2, 1, 1, 1) | scenario prefix of the intent name |

Section 4 of [`docs/implementation_notes.md`](../docs/implementation_notes.md) relates these
group structures to the statistics given in the paper.

**Few-shot orderings** (Appendix C.1). `fewshot/seed<seed>.json` stores, for every intent,
the first 16 entries of a seed-defined random ordering of its training examples (0-based
line numbers of `train.jsonl`). The `b`-shot subset consists of the first `b` entries of
every intent, so the subsets for the budgets used in the paper (1, 2, 4, 8, 16 in the
label-efficiency sweep, 10 in the main comparison, 5 and 10 in the backbone comparison) are
nested, with `n = b · m` training labels. The orderings are produced by
`sigma.data.fewshot.class_orderings` for the seeds 13, 21, 42, 87 and 100.

**Synthetic routing task.** `synthetic/quickstart/` is the output of
`sigma.data.synthetic.make_synthetic_data(seed=13, num_groups=2, classes_per_group=3)`: six
intents in two groups, each bound to an arbitrary routing destination, with 16 training, 4
development and 8 test utterances per intent built from intent keywords and filler words.
The pipeline generates this task in code from the seed; the files are a reference copy.
